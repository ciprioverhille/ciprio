01 — Contexte

L'analyse vidéo des pros. Pour tous les staffs.

Dans le football professionnel, chaque match est décortiqué par une équipe d'analystes. Ailleurs, les staffs filment leurs matchs mais manquent de temps et d'outils pour exploiter 90 minutes de jeu. Ciprio apporte cette lecture précise, appuyée sur les données, à tous les clubs.
